# 飞升路线（主修1 + 辅修2，辅修资源消耗加倍）
修炼建议: 主修炼金，辅修炼体+修仙

| 路线 | 描述 |
| :---: | :---: |
| **魔法** | 通过远古咒语、元素共鸣与灵魂淬炼突破肉体桎梏，最终可成为元素之神、秩序之主或混沌之源。分支：**光明魔法**（秩序、净化）与**黑暗魔法**（混沌、吞噬）。 |
| **修仙** | 吸收天地灵气锻炼自身，提高各项属性，可飞行，但实力发挥被限制在主世界。(圣人道) |
| **炼体** | 极端淬炼肉体，获得强大肉身，不依赖虚空能量，但缺乏对抗虚空能量的手段。 |
| **化意** | 将自身献祭给虚空主神，成为主神的代理人，获得强大但不可理喻的力量，同时沦为木偶。 |
| **炼金** | 发掘万物本质联系并总结规律，最终获得半创世能力，可凭意志塑造万物、制造神器，但会被虚空力量敌视。 |

## 魔法飞升

### 光明魔法
* 阶段一：光之启明者（基础光法、圣光领域、抗诅咒）
* 阶段二：秩序裁决者（圣光审判、秩序烙印、圣光结界）
* 阶段三：永恒辉光之主（光之化身、终焉净化、不灭之光）

### 黑暗魔法
* 阶段一：暗影行者（基础暗法、阴影潜行、吸收负面状态）
* 阶段二：深渊吞噬者（灵魂汲取、痛苦共鸣、地狱熔火）
* 阶段三：混沌归一者（混沌之影、终焉吞噬、永续之暗）

## 修仙飞升
获得任一修炼功法后**引气入体**解锁

### 灵根
* 属性：五行，雷，光，暗，灵
* 品质：极品，优等，普通，低等，劣品

### 境界
* 练气
  * 引气入体后可获得**魂素碑刻**，使用后可以查看自身的**灵根**属性
  * 拥有灵根并可以吸收天地灵气
* 筑基
  * 解锁御剑飞行与元素攻击技能
* 金丹
  * 解锁凭空飞行与死亡后立即重生能力，进一步调整强化元素攻击能力
  * 复活一次消耗金丹的 10% 耐久，以每小时 1% 速度恢复金丹耐久，需要法力值才可回复
* 元婴
  * 加速体内金丹的恢复速度，并增加重生次数，进一步增强法力最大值与元素攻击能力
* 化身(化神)
  * 体内拥有法力分身，不会因时间而衰老，能消耗法力延缓他人衰老速度
  * 所有伤害都由这具分身承担
  * 在分身被摧毁之前本体都不会受到伤害
  * 最大生命值为本体最大生命值的三倍，以0.85% hp/s的速度恢复
* 合体
  * 吸收天地规则为一体，不再能够被常规手段击杀，无法逃脱规则伤害
  * 能够创建独属于个人的规则领域
    * 领域内自身发起的所有攻击都无法被敌人闪避
    * 敌人所有针对自身的常规攻击都将无效化
* 大乘
  * 体内法力分身数量提高到10个，同时自身全基础属性提升100%，额外获得10%伤害减免能力。
  * 可消耗体力以补充法力，或消耗法力以补充体力，法力与体力的兑换比值为1:1。
  * 龙族可使自身原形免疫50%规则伤害，同时能够强行开启并进入到空间裂缝。
* 渡劫
  * 能够强行撕开空间裂缝，借助时空乱流任意前往到已知地点。
  * 龙族可额外获得镇压空间裂缝出口处敌对单位的能力（使敌对单位全属性下降90%）；
* 凝虚化实
  * 进入到凝虚化实后，修者通过初级的时间流动感悟，能够在众多熵增规则中把握存在本质，化混沌为秩序，化虚无为有形。本质上是借助对世界运作的规则感知触碰世界底层逻辑，并在一定程度上为自身提供各种增益。 
  * 在凝虚化实境界后，修者需要不断前往残存的世界时间河流域，借助时间之力的冲刷不断斩去老化的时间特性，获得新生的时间命力与修为并击败死亡命劫，才能进一步提升修为。
  * 此境界修者根据实力的区别可从弱到强分为以下阶段：
    * 时墟境界：初步踏入凝虚化实境界的修者，力量强度与掌握熟练度均十分青涩。
    * 时环境界：完成了第一重洗刷蜕变后成功打破境界桎梏的修者。
    * 时心境界：完成百次渡时间命劫的修者，能够自由感知时间之河的位置与前去的通道。
    * 时河境界：主动斩断修为与命力，自毁根基后浸泡在时间之河中由时间河水重塑自身，最终完整感悟时间之力。
* 菩提三线
  * 进入到菩提三线境界后的个体将成功做到超凡脱俗，与世界本源的联系更加紧密，其获取力量的途径也更改为与世界本源的同调共鸣，契合度越高，实力越强。反之，若前往其他世界，则会失去全部修为，需要从头再来。古老帝族将不断在各个世界积累修为的菩提修炼者称为**天行修者** 
  * 在菩提境界后，修者需要不断前往新的世界不断重新获得修为并击败死亡命劫，才能进一步提升修为。
  * 天行修者根据实力的区别可从弱到强分为以下阶段： 
    * 天王境界：初步踏入菩提境界的修者，力量强度与掌握熟练度均十分青涩。 
    * 天君境界：完成了第一重跨界重生蜕变后成功打破境界桎梏的修者。
    * 天尊境界：完成百次渡命劫的修者，能够自由穿梭于各个世界或位面而不丢失实力。 
    * 天神境界：主动斩断修为与命力并重新达到天尊境界后的修者，能够在一定程度上修改世界意志与时间方向。
* 时间之环
  * 当修者将天地、时间、规则的力量融于己身，于体内开辟新天地后，便踏入了“时间之环”境界。
  * 此境修者自身化为一个独立的轮回系统，不再依赖外界天地，而是依靠体内天地的永恒运转获得力量与不朽。
  * 此境界修者根据体内天地的演化程度与意志权能的范围，可从弱到强分为以下阶段
    * 内环：初步开辟体内天地，轮回初成，天地运转尚显生涩。
      * 修者主要依赖体内天地的自循环提供力量，能初步抵抗外界的时间冲刷与规则侵蚀，但体内天地规则尚不圆满，需不断从外界掠取时间碎片与规则残片进行补全。
    * 定环：体内天地法则趋于稳固，轮回脉络清晰成型。
      * 修者能主动加速或减缓体内天地的轮回流速，以此爆发出远超常理的力量与恢复速度。此阶段修者开始能模糊感应到其他世界的轮回波动，但无法进行实质干预。
    * 恒环：体内天地达成完美的自洽循环，生生不息，不假外求。
      * 修者的意志已与体内天地的轮回法则深度绑定，时间与规则类攻击会被体内天地自然同化吸收。此阶段修者能够抵御绝大多数外界轮回意志的干扰，稳固自身道基。
    * 外环：体内天地不仅内循环圆满，更能向外辐射“环之力”，形成专属的法则力场。
      * 在此力场内，修者可以有限度地扭曲、重演局部的时间片段与规则排序，如同在自身画出的“环”中成为临时的造物主。此乃干涉外界轮回进程的起始。
    * 界环：修者彻底摆脱单一世界轮回的束缚，自身成为游走于无尽轮回之上的“界环”。
      * 可同时将意志投射至多个世界的轮回进程中，并行观测与干预。此阶段修者不灭的本质已深植于轮回概念本身，即便肉身与体内天地被同时摧毁，其“环之烙印”仍可在时间长河的某处重新凝聚。
    * 生灵世环：当修者达到界环境界，自身化为游走于无尽轮回之上的“界环”后，若想再进一步，便需将目光从外界收回，投向体内天地中最深邃的空白——生命。
      * 此境界修者不再满足于天地法则的自洽运转，而是主动点燃体内天地的本源之火，催生万物生灵，让体内世界从“规则天地”蜕变为“生命乐土”。
      * 此境界修者根据体内生灵文明的繁荣程度与香火愿力的凝聚层次，可从弱到强分为以下阶段：
        * 启灵境：修者以自身意志为引，将一缕轮回灵光播撒于体内天地之间，促成原生生灵的诞生。
          * 最初诞生的生灵灵智蒙昧，生死轮回粗浅原始，但其每一次生灭、每一次挣扎求存，都会为修者带来最纯粹的“生命源力”，缓慢反哺体内天地的底蕴厚度。
        * 化民境：体内生灵繁衍壮大，形成部落与族群，开始具备粗浅的文明雏形与朴素的信仰图腾。
          * 修者能隐约感知到生灵的集体意志，并借助其香火愿力淬炼自身神魂。生灵族群在战争、迁徙、求存中迸发的生命火花，会化作点点灵光融入体内天地轮回，使修者的力量不再局限于规则层面，开始触及“生机”的本质。
        * 立国境： 体内文明建立稳定的王朝或宗派体系，生灵拥有了系统的修炼法门与文化传承。
          * 修者能清晰接收并调度整个文明的愿力洪流，以此为燃料加速体内天地的扩张与法则的精细化。
          * 生灵中的佼佼者在突破自身极限时，其顿悟与升华会直接反馈给修者，使其对时间与规则的感悟产生崭新的灵光。
        * 万灵境： 体内文明百花齐放，万族林立，生灵的修炼路径覆盖了修者所知的一切道途。
          * 修者与体内亿万生灵形成深度的共生共鸣——生灵研习时间法则，修者则更通透时间的褶皱；生灵参悟毁灭之道，修者则更明晰秩序的边界。
          * 每一条新的修行路在体内世界被走通，修者便多一条触及终极的视角。
        * 世环境：体内世界自成寰宇，生灵繁衍已至鼎盛，其文明的生灭兴衰、个体的爱恨情仇、族群的争鸣与交融，共同构筑了一个完整而鲜活的“生灵大轮回”。
          * 修者的意志升华为此方世界的“天理”，不需主动干预，生灵自身的欲望与追求便会推动轮回滚滚向前，自发为修者孕育新的规则变数与生命奇迹。
          * 至此，修者与体内生灵彻底化为一体——生灵不灭，则体内天地不衰；天地不衰，则轮回不止；轮回不止，则修者与道同存，生生不息，前路无尽。

## 炼体飞升

### 境界
* 铸身期
  * 全属性翻倍提升，对常规攻击造成的伤害额外拥有50%减免；
  * 解锁钢骨，可在10s内免疫控制效果并使护甲值提升7000%，钢骨的每次催动都需要消耗20%体力，催动后需要等待10Mins以冷却；
* 锻身期：
  * 解锁千锤劲，锁定单一目标后可在20s对其发动无视护甲的真伤攻击，伤害能力等同于自身的各条件叠加后的总数值。千锤劲冷却时间10s；
  * 解锁不灭意志，在濒死时立即恢复100%生命值，在10Mins内生命值、体力值与护甲值额外提升900%。不灭意志冷却时间 2Days；
* 觉醒期：
  * 神力圣甲：可自由召唤属于自身的肉体铠甲，额外获得300%生命值与无限体力值；
  * 法意开天：短暂开启自身的意志领域，领域范围内，自身造成的所有攻击都无法被闪避和减免伤害；
  * 圣甲内爆：召唤圣甲后可自由选择引爆铠甲，对自身造成20%生命值伤害，同时基于自身生命值上限，对敌方造成自身生命值上限的99700%的真伤（无视护甲，但可以被术法、符箓等手段减免）；

## 炼金飞升

### 境界
* 前期：元素调和：
  * 能够使用大量基础元素调和制作为各种稀有元素，并可以提高已有装备的耐久表现；
  * 能够制作一次性的符文与药剂，提供短暂的小幅度增益；
  * 对元素类法术攻击拥有抗性，免疫元素控制；
* 中期：元素编织：
  * 能够制作一些属性在一定范围内自定义的傀儡，帮助执行任务、制作与战斗；
  * 将常规攻击化解为元素，并将其拆解、重构以作为自己的防御或攻击手段；
  * 短暂创建元素领域，领域内，敌方的所有元素与魔法攻击都将被削弱，同时所有场地内自然元素都可被作为武器进而调用；
* 后期：创世工匠：
  * 可消耗体力与周遭元素物质创建“元素生命体”，此类人造物种只听命于创建者；
  * 可消耗体力与周遭物质修复自身躯体的损伤；
